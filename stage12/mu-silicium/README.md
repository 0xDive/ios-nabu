# Stage 12a — isolated Mu-Silicium UEFI build for Xiaomi Pad 5

This experiment builds the *existing upstream nabuPkg* in [UniXNU/uefi-sheng](https://github.com/UniXNU/uefi-sheng/tree/sheng/Platforms/Xiaomi/nabuPkg). It does not replace our proven edk2-msm firmware, patch PM8150B USB-C registers or change Android partitions.

## Pinned input
- UniXNU/uefi-sheng branch `sheng` @ `0eb4514db0744b8136a3897ab1af93b713c2c27b`.
- The pinned upstream Git submodule `Binaries` is [Project-Silicium/Device-Binaries](https://github.com/Project-Silicium/Device-Binaries) @ `a1501e0c2e642d6ac0d8f52c85af2a67b75a7799`.
- Its own `Resources/Configs/nabu.toml`, `Resources/DTBs/nabu.dtb`, `Platforms/Xiaomi/nabuPkg/nabu.dsc` and `HanaPkg` are used without rewriting hardware configuration.

The upstream configuration uses the **Android boot header v1**, unlike the v3 container generated by our prior edk2-msm workflow. The bootloader acceptance of this header with `fastboot boot` **has not been tested** on the user's tablet. Never flash this image.

## CI deliverables (only when the build *and* audit pass)
- `Mu-nabu.img` — *experimental, hardware-unverified* one-time boot candidate.
- `SILICIUM_UEFI.fd` — firmware device image, 3 MiB.
- `image-audit.json` — host-side unpack check for gzip BootShim + exact FD + appended pinned DTB.
- `SHA256SUMS`, `README-FIRST.txt` — provenance and safety note.

The validator checks the raw Android kernel field against a decompressed BootShim/FD and the pinned DTB; **none of those checks prove a working UEFI, functioning USB, or a runnable XNU kernel**.

**Do not change partitions.** Keep our last known working edk2-msm image. If any image test is later explicitly undertaken, it must be `fastboot boot` only with a recovery path.

## XNU integration boundary
UniXNU uses XNU `10063.141.1` and a **4 KiB** machine configuration, while our existing `xnu-nabu.yml` compiled a research NABU Mach-O based on XNU `8796` and mechanically staged sweet patches. Those are different kernel ABIs: **do not feed the existing Mach-O into DarwinBoot without an independently reviewed entry ABI, boot_args, memory map and matching UniXNU 4 KiB kernel**. See `stage12/unixnu/`.
